# 🥋 Aventura dos Irmãos Miau

**Aventura dos Irmãos Miau** é um jogo de combate 2D em desenvolvimento, criado em Java, com foco em artes
marciais e diferentes estilos de luta.

O projeto está sendo desenvolvido inicialmente a partir do jiu-jítsu brasileiro, com a proposta de expandir
futuramente para outras modalidades e personagens.

**Tecnologias:** Java, Swing e Java2D.

**Status:** em desenvolvimento.
