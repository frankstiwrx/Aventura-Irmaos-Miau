# 🐱 Aventura dos Irmãos Miau

Um pequeno jogo 2D desenvolvido em Java, criado principalmente para praticar programação e experimentar algumas ideias de gameplay.

O jogo acompanha dois irmãos gatos praticantes de jiu-jitsu: Miau Branco e Miau Preto.

O projeto ainda está em desenvolvimento e novas mecânicas e animações serão adicionadas aos poucos.

## 🛠️ Tecnologias

- Java
- Java Swing
- Java2D
- Maven
